03 / SYSTEM GAPS

WHAT IS STILL MISSING?

不是缺更多零散技术，
而是缺几条完整闭环。

以下判断只基于当前论文证据。已有履历或合作能力但尚未形成公开论文闭环的部分，不被算作“已经系统掌握”。

P1G01

从风味识别走向因果确认

当前证据
已具备 GC-O、OAV、AEDA 与多平台指纹。
缺失环节
稳定同位素稀释定量、香气重组 / 缺失实验、真实基质阈值与释放动力学。
建议动作
选一个优势产品，补齐 identification → quantification → recombination → sensory validation 闭环。
P1G02

从专业感官走向消费者科学

当前证据
专业描述性感官和仪器关联较强。
缺失环节
消费者分群、偏好图、动态感官方法、跨文化与真实食用情境研究。
建议动作
在 FlavourMind 中固化 CATA / RATA、TDS / TCATA、偏好映射和样本量设计。
P1G03

从可调用平台走向整合型多组学

当前证据
Orbitrap、QTOF、GC-QTOF、色谱、流式与分子平台均可稳定调用，论文已覆盖挥发组和 16S。
缺失环节
跨平台样品前处理、统一质控、非靶向代谢组 / 蛋白组及可复现的数据融合流程。
建议动作
围绕一个优势问题建立 SOP、质控样、数据字典和外部验证，形成真正属于团队的多组学工作流。
P1G04

方法学验证与标准化深度

当前证据
大量方法已用于回答具体产品问题。
缺失环节
系统的 LOD / LOQ、回收率、精密度、不确定度、实验室间验证和标准物质体系。
建议动作
把高频分析流程沉淀为 SOP、质控样、验收规则与可审计数据结构。
P1G05

多源数据融合与外部验证

当前证据
已使用 PCA、聚类及感官-化学关联。
缺失环节
可解释机器学习、因果模型、独立样本验证、跨批次迁移与模型失效监测。
建议动作
用 Flavor Intelligence Workbench 建立训练集 / 验证集边界和模型证据等级。
P2G06

从实验室最优走向放大与经济性

当前证据
擅长定位工艺窗口和品质机制。
缺失环节
DOE / QbD、生产线放大、包装耦合、加速货架期模型与技术经济评价。
建议动作
每个企业项目增加 pilot validation、成本约束和量产验收三个固定阶段。
P2G07

人体功效的机制与可重复性

当前证据
已有随机双盲试验、菌群和临床指标。
缺失环节
预注册、多中心、功效量估计、shotgun / 代谢组、因果中介与长期随访。
建议动作
围绕一个菌株-机制-结局主线做深，避免功效主题横向扩散。

企业真正需要的，通常不是“做一个检测”。

而是把一个模糊问题，
变成可验证、可决策、可迭代的研发路径。
